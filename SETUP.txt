INVARIANT — WHAT YOU NEED TO ADD
================================

The site is a white, single-page landing page. It already runs.
The front of the page is a full-width photograph. Drop the file
in, refresh, and it fills the screen. The headline stays in the
top left.


RUN IT AGAIN LATER
------------------

1. Open a terminal in this folder.
2. npm install
3. npm run dev
4. Open the local URL Vite prints (usually http://localhost:5173).

Production build: npm run build
The finished site is the dist folder. Upload that, or connect the
repo to Vercel or Netlify and use the same build command.


1. THE FRONT PHOTOGRAPH
-----------------------

This is the one that matters. File name: hero.webp (or .jpg).
Folder: public/images/

Shoot invariant.one with a MacBook on it, wide enough to fill a
screen. Keep the top left fairly quiet. That is where the
headline sits. About 2400 x 1600, or a wider 2x of a laptop
screen (2880 x 1620). The page crops with object-fit: cover.

hero.jpg, wide.jpg, edge.jpg, and signal.jpg are the four
photographs the page uses.

2. PHOTOGRAPHS
--------------

Folder: public/images/

The page looks for each name below as .webp, .jpg, .jpeg, .png,
or .avif, in that order. Use the base name exactly. Until a file
exists, you will see a quiet poster with the filename in the
corner so you know which slot it is.

  hero.jpg       Desktop front page. invariant.one with a MacBook.
  wide.jpg       Phone front page, and the first photo in the slider.
  edge.jpg       Last photo in the slider.
  signal.jpg     Second photo in the slider.

These four are the whole set. The page does not ask for more.
A shared link uses hero.jpg as the preview.

Suggested shoot: soft daylight from one side, real table, lots of
empty space, sRGB, long edge around 2400px. Do not bake captions
into the photo. The page adds them.

Want a different caption? Edit the title fields in src/config.ts
on slides.

3. PRE-ORDER FORM  (do this before you send the link to anyone)
----------------------------------------------------------------

Right now the form works on your machine only. A request is saved
in that browser (localStorage key: invariant-preorders). Nobody else
can send you the name. The line under the button says nothing is charged.
Connect the form before anyone else uses the page.

  a. Create a form at https://formspree.io (or any endpoint that
     accepts a JSON POST).
  b. Copy .env.example to a new file named .env.local
  c. Set the value:

       VITE_PREORDER_ENDPOINT=https://formspree.io/f/your-id

  d. Stop the dev server and start it again. Vite only reads
     env files at startup.

The JSON fields sent are: name, email, use, quantity, product.

If you already have a checkout page instead, set preorderUrl in
src/config.ts to the full https URL. The nav and hero buttons
will open that. The form on this page stays either way.

Nothing on this page charges a card. Do not tell people it does
until a real checkout exists.

There is a hidden "company" field. If it gets filled, the submit
is ignored. Leave it alone.


4. REAL SPECS YOU STILL NEED TO GIVE ME, OR TYPE IN YOURSELF
-------------------------------------------------------------

I only used what you told me: 99.6 Wh, up to 14 hours, MacBook
form factor, a personal SIM hotspot, and it charges all your
devices.

I did not invent a price, output wattage, ports, weight,
thickness, colors, carrier, data plan, or ship date. Those will
look made up if I guess.

When you know them, edit src/config.ts:

  price            Shows on the pre-order card when not empty.
  specs            Add rows. Each row is { label, value }.
  specsNote        Small print under the list. Put the battery
                   test conditions here when you have them
                   (which laptop, screen brightness, and so on).
  contactEmail     Shows in the footer.
  socials          { label, href } objects. Empty means no icons
                   and no fake accounts.
  slides           The photos under the hero, and their captions.
  copy             The hero line, the short description, and the form.
  useCases         The chips on the form.

The numbers live in specs. Change them there.
